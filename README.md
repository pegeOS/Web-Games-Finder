Site que reúne todos os tipos de jogos "Trivia Diários", onde, a cada dia, você recebe um desafio para resolver ( pode ser relacionado a diversas coisas, como jogos, palavras, filmes, lógica, etc).
O Web Games Finder utiliza um design amarelo em pixel e, em cada jogo, você recebe a descrição e pode ir direto para ele apenas com 1 clique. Você também pode acessar seus jogos favoritos ( escolhidos
por você) e seu histórico sem nem fazer login e colocar seus dados em risco.
